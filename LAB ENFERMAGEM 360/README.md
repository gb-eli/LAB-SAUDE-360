# Laboratório Virtual de Enfermagem — v0.1.0

Base modular para GitHub Pages.

## Subir no GitHub

Extraia este ZIP e envie **os arquivos e pastas internos diretamente para a raiz do repositório**.

A raiz deve ficar assim:

```text
index.html
.nojekyll
VERSION.txt
CHANGELOG.md
ATUALIZACOES_MODULARES.md
README.md
app/
core/
services/
ui/
data/
modules/
docs/
```

Não precisa de Node.js, npm ou build.

## Atualizações futuras

A partir desta versão, as entregas podem ser incrementais: subir somente os arquivos/pastas alterados.

Veja `ATUALIZACOES_MODULARES.md`.
