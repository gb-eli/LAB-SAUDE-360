# Presets Personalizados com Tags — v0.34.0

## Limites

- 20 presets locais;
- 8 tags por preset;
- 28 caracteres por tag.

## Busca

A busca considera:
- nome;
- aula;
- competência;
- tags;
- sistemas;
- estruturas.

Os tokens digitados usam lógica AND.

## Edição

Editar metadados não altera automaticamente o estado A/B já salvo.

A opção:

`Atualizar estado A/B ao editar`

é necessária para substituir o estado.

## Duplicação

Uma cópia mantém o estado e metadados, recebendo nome:

`Nome original — cópia`

## Importação

Presets antigos sem `tags` continuam válidos.

As tags ausentes são normalizadas para lista vazia.
