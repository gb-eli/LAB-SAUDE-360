# v0.15.0 — Anatomia Integrada e Preset Visual Clínico

Foram adicionados cinco laboratórios independentes:
- Cardiovascular;
- Endócrino;
- Linfático;
- Cabeça e Pescoço;
- Olho e Ouvido.

Foi criado o `ClinicalScenePreset`, uma camada visual compartilhada para ambientes 3D.

A melhoria visual foi aplicada sem alterar os contratos dos módulos e sem criar qualquer diferenciação de usuário.

Todos os modelos anatômicos continuam declarados como representações didáticas esquemáticas.
