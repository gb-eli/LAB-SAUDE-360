# Estilos de Marcadores — v0.33.0

## Serviço

`ComparisonMarkerStyleManager`

## Configurável

Para cada categoria:
- cor hexadecimal;
- ícone curto.

## Categorias base

- Estrutura ●
- Atenção ⚑
- Relação ↔
- Dúvida ?

## Persistência

Chave local:

`comparison-marker-styles`

## Reset

É possível restaurar uma categoria individual ao estilo padrão.

## A/B

Enquanto `Estrutura` não possuir override:
- A usa verde;
- B usa rosa.

Ao personalizar a categoria Estrutura, a cor escolhida passa a ser deliberadamente compartilhada.
