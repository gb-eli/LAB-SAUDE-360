# Decisão — Interface Unificada

A plataforma é um laboratório virtual front-end de exploração.

Não há papéis funcionais diferentes para professor e aluno.

Professor e aluno podem abrir o mesmo endereço e utilizar os mesmos recursos.

Roteiros e jornadas são auxiliares de exploração, não modos de acesso.

A sessão é opcional e local.

A arquitetura futura deve preservar esta decisão, a menos que ela seja explicitamente alterada.
