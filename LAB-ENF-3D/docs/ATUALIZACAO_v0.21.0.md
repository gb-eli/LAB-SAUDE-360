## Loading
Novo `LoadingIndicatorManager.js`.

O sistema é baseado nos eventos do loader compartilhado e funciona automaticamente em todos os módulos GLB.

## Acessibilidade
- canvas 3D focável;
- rotação e zoom via teclado;
- `aria-busy`;
- `aria-live`;
- foco visível;
- botões com alvo mínimo em mobile;
- reforço de `prefers-reduced-motion`.

## Compatibilidade
Continua sem backend obrigatório e compatível com GitHub Pages.
